# Proyecto-Final---Taller-de-Programaci-n-Web
Sitio web con varias páginas enlazadas entre sí, orientado a la reducción del desperdicio de alimentos, permitiendo que restaurantes o negocios oferten comidas próximas a vencer a precios accesibles.
El sitio web debe contener las siguientes páginas principales:
● Iniciar sesión (login.html)
● Registrar Usuario (registrar.html)
● Inicio (index.html)
● Menú de Comidas (menu.html)
● Formulario de Pedido (form_pedido.html)
● Tabla de Pedidos Realizados (pedidos.html)
● Ofertas Especiales (ofertas.html)
